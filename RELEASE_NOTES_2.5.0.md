# Shopify–Alibaba Terminal Orchestrator 2.5.0

La version 2.5.0 approfondit la version 2.4.0 sans retirer son architecture, ses fichiers historiques ni son terminal à lignes fixes.

## Principaux approfondissements

- réconciliation profonde et persistante;
- rapports et panneaux terminal à données bornées;
- transports Shopify/Alibaba instrumentés;
- workers et workflows avec délais, reprises et statistiques;
- agents spécialisés et modèles explicables faibles ressources;
- webhooks, API et files renforcés;
- mappers Shopify complets;
- machines d’état et événements de domaine auditables;
- widgets C++ natifs développés;
- profil Windows deux cœurs / deux gigaoctets préservé.

Les mutations externes demeurent bloquées pendant les validations en mode sec.
