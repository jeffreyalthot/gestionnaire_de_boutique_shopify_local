CATALOGUE DES URL ET MÉTHODES API ALIBABA.COM
Portée : produits, commandes, logistique, paiements, fournisseurs, OAuth, webhooks/messages
Date de compilation : 2026-07-24
====================================================================================================

IMPORTANT
---------
1. Alibaba.com utilise principalement une passerelle API commune. Le nom de l’API est transmis
   dans le paramètre « method ». Une URL différente est donc construite pour chaque méthode.
2. Toutes les méthodes de passerelle requièrent normalement un APP_KEY, un horodatage, une
   version de protocole, une méthode de signature et une signature générée avec APP_SECRET.
3. Les méthodes marquées « session Oui » exigent aussi le jeton d’accès du vendeur ou de l’acheteur.
4. Certaines méthodes sont visibles dans la documentation publique mais restent réservées à des
   partenaires, programmes ICBU/GGS, OneTouch, AMES, Ceres, dropshipping ou permissions financières.
5. Ce catalogue couvre les méthodes publiquement documentées trouvées dans les catégories demandées.
   Les API internes non publiées ou affichées uniquement après approbation ne peuvent pas être
   garanties avant l’activation du compte développeur et l’attribution des permissions.

PASSERELLES PRINCIPALES
-----------------------
HTTPS recommandée : https://eco.taobao.com/router/rest
HTTPS globale historique : https://api.taobao.com/router/rest
HTTP historique : http://gw.api.taobao.com/router/rest

PARAMÈTRES COMMUNS
------------------
method={NOM_API}
app_key={APP_KEY}
session={ACCESS_TOKEN}                 # requis pour les données de compte autorisées
timestamp={YYYY-MM-DD HH:MM:SS GMT+8}
format=json
v=2.0
sign_method=hmac ou md5                # certaines docs utilisent hmac-sha256 pour TMC
sign={SIGNATURE_CALCULÉE_AVEC_APP_SECRET}
partner_id={IDENTIFIANT_PARTENAIRE}    # optionnel
target_app_key={APP_KEY_CIBLE}         # seulement pour API tierces

MODÈLE COMPLET
--------------
https://eco.taobao.com/router/rest?method={NOM_API}&app_key={APP_KEY}&session={ACCESS_TOKEN}&timestamp={TIMESTAMP_ENCODED}&format=json&v=2.0&sign_method=hmac&sign={SIGNATURE}
