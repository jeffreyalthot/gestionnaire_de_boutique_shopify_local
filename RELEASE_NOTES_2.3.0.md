# Version 2.3.0 — approfondissement fonctionnel

Cette version conserve intégralement la branche 2.2.0 et approfondit les agents déterministes,
les modèles faibles ressources, les webhooks Shopify, les canaux de vente, la gestion de la
boutique, la qualification fournisseur, la fiscalité, les portes qualité et le workflow de
commande fournisseur. Le générateur de TREE associe désormais un statut de développement à
chaque fichier et publie aussi un inventaire JSON exploitable par les outils de qualité.
