# Retard d’expédition

## Déclencheur

Alerte de santé persistante ou erreur de capacité confirmée.

## Procédure

1. Comparer la promesse client aux événements de suivi.
2. Demander une mise à jour au fournisseur.
3. Notifier le client avec une date prudente.
4. Escalader colis perdu après le seuil configuré.

## Critère de sortie

Intégrité validée, files réconciliées et aucune mutation dupliquée.
