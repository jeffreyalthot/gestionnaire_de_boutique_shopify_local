# Dérive d’inventaire

## Déclencheur

Alerte de santé persistante ou erreur de capacité confirmée.

## Procédure

1. Bloquer les nouvelles allocations du SKU.
2. Comparer Shopify, réservations locales et stock fournisseur.
3. Libérer seulement les réservations expirées.
4. Réconcilier puis réactiver le SKU.

## Critère de sortie

Intégrité validée, files réconciliées et aucune mutation dupliquée.
