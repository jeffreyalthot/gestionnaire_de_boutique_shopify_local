# Légende des statuts du TREE

- ✅ COMPLET : implémentation substantielle et syntaxe valide.
- 🧪 TEST : test automatisé collecté par la suite de validation.
- 🛠 DÉVELOPPÉ : logique réelle présente; approfondissement encore possible.
- 🔗 INTÉGRATION : configuration, contrat, schéma, requête ou ressource d'intégration.
- 📚 DOCUMENTATION : documentation ou procédure opérateur.
- 📦 ARTEFACT : paquet généré ou fichier de distribution.
- 📁 DONNÉES : sentinelle ou espace persistant de données.
- ⚠ À APPROFONDIR : module très court ou adaptateur minimal restant.
- ❌ ERREUR : fichier illisible ou syntaxe invalide.

`PROJECT_TREE.txt` et `PROJECT_FILE_STATUS.json` sont générés par
`python -m tools.generate_status_tree`.
